# ДЗ №4. Лента постов друзей

`GET /post/feed` показывает до 1000 последних постов друзей. Сначала идут самые свежие публикации и правки. `limit` задаёт размер страницы, а `offset` — сколько постов пропустить. Для запроса нужен токен из `/login`.

## Запуск

Нужны Docker и Docker Compose. Выполните из корня репозитория.

```bash
test -f .env || cp .env.example .env
docker compose up -d --build --wait
docker compose exec -T app python -m app.feed_admin seed
```

Последняя команда добавляет четырёх пользователей, двух друзей для демопользователя и 1051 пост. В API-документации можно попробовать методы для друзей и постов. [Swagger](http://localhost:8080/docs)

## Как посмотреть ленту

Войдите под демопользователем и запросите три последних поста. Для примера нужны `curl` и `python3`.

```bash
API=http://localhost:8080
VIEWER=00000000-0000-0000-0000-000000004001
TOKEN=$(curl -fsS "$API/login" \
  -H 'Content-Type: application/json' \
  -d "{\"id\":\"$VIEWER\",\"password\":\"Feed-demo-2026\"}" \
  | python3 -c 'import json, sys; print(json.load(sys.stdin)["token"])')

curl -fsS "$API/post/feed?limit=3" -H "Authorization: Bearer $TOKEN"
```

На свежих демоданных вернутся посты №1050, №1049 и №1048. Запрос с `offset=999&limit=2` вернёт только пост №51, а с `offset=1000` вернёт `[]`. Пост №1051 написан пользователем вне списка друзей.

## Как работает кэш

Посты и список друзей хранятся в PostgreSQL. Redis хранит подборки постов по авторам и готовую ленту каждого пользователя. При первом запросе приложение собирает ленту из подборок. Если подборки ещё нет в Redis, приложение загружает её из PostgreSQL.

При создании, правке или удалении поста меняется версия постов автора. Ключ готовой ленты зависит от состава друзей и этих версий, поэтому следующий запрос после изменения соберёт актуальную ленту. Старые записи удаляются из Redis по истечении 15 минут.

После перезапуска Redis лента восстановится при первом запросе. Чтобы сразу перестроить её из PostgreSQL для демопользователя, выполните команду ниже.

```bash
docker compose exec -T app python -m app.feed_admin rebuild 00000000-0000-0000-0000-000000004001
```

## Тесты

```bash
docker compose --profile test run --rm tests pytest -q -p no:cacheprovider tests/test_feed.py
```

Тесты проверяют лимит в 1000 постов, разбиение на страницы, обновление ленты после изменений и восстановление кэша.
